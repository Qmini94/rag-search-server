# 관리자 UI

## 개요

관리자 페이지는 `/business` 경로 하위에 위치한다. `business-sub` 레이아웃을 사용하며, Element Plus 컴포넌트 기반이다. 다크 모드를 지원한다.

## 페이지 구성

| 경로 | 기능 | 주요 컴포넌트 |
|---|---|---|
| /business | 대시보드 | - |
| /business/homepage/board | 게시판 관리 | BoardCreate, BoardDetail |
| /business/homepage/content | 콘텐츠 관리 | ContentEdit |
| /business/homepage/popup | 팝업/배너 관리 | PopupBuilder |
| /business/homepage/style | CSS 편집기 | CodeMirror 통합 |
| /business/homepage/asset | 에셋 탐색기 | Explorer, FileGrid, FolderTree |
| /business/site/site_manage | 사이트 설정 | SiteManager |
| /business/site/menu_manage | 메뉴 관리 | TreeEditor, DragDrop |
| /business/site/member_manage | 회원 관리 | MemberManager |
| /business/site/permission_manage | 권한 관리 | PermissionMatrix |
| /business/apply | 신청 관리 | AdminApplyList, AdminApplyDetail |
| /business/log/access | 접근 로그 | AuditLog |

## 게시판 관리

### 생성 흐름 (BoardCreate)

4단계 스텝으로 게시판을 생성한다.

```
Step 1: 기본 정보
  - boardId (영문, 테이블명으로 사용)
  - boardName (표시 이름)
  - boardType 선택 (LIST/GALLERY/FLOW 등)
  - theme 선택

Step 2: 옵션 설정
  - 13가지 게시판 옵션 토글
  - 파일 첨부 설정 (크기, 개수, 확장자)

Step 3: 필드 정의
  - 프리셋 필드 확인
  - 커스텀 필드 추가/수정/삭제
  - 필드 타입, 필수, 검색 가능, 암호화 설정

Step 4: 확인 및 생성
  - 전체 설정 리뷰
  - POST /back-api/boardMaster (생성)
```

### 상세/수정 (BoardDetail)

기존 게시판 설정 조회 및 수정. 같은 스텝 구조 사용.

## 콘텐츠 관리

에디터에서 HTML 콘텐츠를 작성/수정한다. 버전 관리 지원.

```
콘텐츠 목록 → 그룹 상세 → 버전 목록
  ├─ 새 버전 추가
  ├─ 버전 전환 (activeContent)
  └─ 버전 삭제
```

## 메뉴 관리

트리 에디터로 메뉴 구조를 관리한다.

```
드라이브 선택 (www, business 등)
  └─ 트리 뷰:
      ├─ 드래그 앤 드롭으로 순서/계층 변경
      ├─ 메뉴 추가 (folder/board/content/script/link)
      ├─ 메뉴 삭제
      └─ 저장 → syncMenuTree() 호출
```

## 권한 관리

메뉴별 권한 매트릭스를 설정한다.

```
메뉴 트리 ← → 권한 매트릭스
  ├─ VIEW: 조회 권한
  ├─ WRITE: 작성 권한
  ├─ MODIFY: 수정 권한
  ├─ REMOVE: 삭제 권한
  ├─ MANAGE: 관리 권한
  ├─ ACCESS: 접근 권한
  ├─ REPLY: 답글 권한
  └─ ADMIN: 관리자 전용

각 권한에 Subject 설정:
  - LEVEL: 사용자 레벨 기준 (ADMIN/USER/GUEST)
  - ID: 특정 사용자 ID 기준
```

## 팝업/배너 관리

타입별 다른 UI 제공.

**LAYER (레이어 팝업):**
- 위치/크기 설정 (leftPx, topPx, width, height)
- 팝업 레벨 스케줄링 (startDate, endDate)
- 오늘 하루 보지 않기 옵션

**VISUAL (비주얼 배너):**
- 이미지 업로드/순서 관리
- 이미지별 스케줄링
- 자동 슬라이드 설정 (간격, 효과)

## CSS 편집기

CodeMirror 6 기반 실시간 CSS 편집.

```
디렉토리 트리 ← → CSS 에디터
  ├─ 파일 선택 → 내용 로드
  ├─ 수정 → 저장 (.bak 자동 백업)
  ├─ 잠금 (lock) 기능
  │   └─ 다른 사용자 편집 중이면 읽기 전용
  └─ 버전 (css-version.json 자동 업데이트)
```

## 에셋 탐색기

이미지 에셋을 디렉토리 구조로 관리.

```
폴더 트리 ← → 파일 그리드
  ├─ 폴더 생성/삭제
  ├─ 파일 업로드 (이미지만)
  ├─ 파일 삭제
  └─ 이미지 미리보기 (크기 정보 포함)
```

## 신청 관리

신청 폼 데이터 관리.

```
신청 목록 (페이징, 검색, 상태 필터)
  └─ 상세 보기
      ├─ 신청자 정보
      ├─ 동반자 정보
      ├─ 첨부파일
      └─ 상태 변경 (StatusChangeModal)
```

## 접근 로그

감사 로그 조회.

```
기간 설정 + 검색 → 로그 목록
  - IP, 사용자, 접근 시간, 경로 등
```
