# 파일 및 에셋 관리

## 개요

Q-CMS는 두 가지 파일 관리 시스템을 제공한다:
1. **게시판 첨부파일** — 게시글에 첨부하는 파일 (자동 썸네일 생성)
2. **에셋 관리** — 사이트 전역에서 사용하는 이미지 자산 (디렉토리 탐색)

## 1. 게시판 첨부파일

### 핵심 파일

| 파일 | 역할 |
|---|---|
| `controller/cms/core/board/BoardFileController.java` | 파일 업로드/삭제 API |
| `controller/cms/core/file/FileController.java` | 파일 다운로드 API |
| `service/cms/core/file/BoardFileService.java` | 파일 CRUD + 동기화 |
| `entity/cms/core/file/BoardFile.java` | 파일 엔티티 |
| `util/ImageResizeUtil.java` | 이미지 리사이즈 |

### API

```
GET    /back-api/board/{postIdx}/files          → 파일 목록
POST   /back-api/board/{postIdx}/files          → 파일 업로드
DELETE /back-api/board/{postIdx}/files/{fileIdx} → 파일 삭제
GET    /back-api/file/download/{menuId}/{fileId} → 파일 다운로드 (302 리다이렉트)
```

**권한**: `@PreAuthorize("@permService.hasAccess(...)")` 어노테이션으로 메서드 레벨 권한 체크.

**다운로드 방식**: FileController는 직접 파일을 스트리밍하지 않고, 정적 파일 경로로 **302 리다이렉트**한다. Nginx가 `/public/` 경로의 정적 파일을 직접 서빙.

### BoardFile 엔티티

테이블: `cms_board_file`

| 필드 | 타입 | 설명 |
|---|---|---|
| idx | Long (PK) | 파일 ID |
| menuId | Long | 메뉴 ID |
| postIdx | Long | 게시글 ID |
| seq | Integer | 표시 순서 |
| origName | String | 원본 파일명 |
| storedName | String | 저장 파일명 (UUID 기반) |
| contentType | String | MIME 타입 |
| sizeBytes | Long | 파일 크기 |
| filePath | String | 상대 경로 |
| isImage | Boolean | 이미지 여부 |
| width | Integer | 이미지 너비 |
| height | Integer | 이미지 높이 |
| description | String | 설명 |

### 파일 저장 구조

```
{uploadBasePath}/
├── original/{menuId}/{postIdx}/{storedName}   원본
├── thumb/{menuId}/{postIdx}/{storedName}      썸네일 (300x300)
└── preview/{menuId}/{postIdx}/{storedName}    미리보기 (800x800)
```

설정:
```yaml
file:
  upload:
    base-path: /data/egovframe-cms/uploads/board
    dir:
      original: original
      thumb: thumb
      preview: preview
  public:
    base-path: /static/board
```

### 업로드 + 동기화 흐름

프론트엔드가 `files` (새 파일) + `meta` (기존 파일 정보)를 multipart로 전송한다.

```
1. 현재 DB 상태 로드
2. keepIds에 없는 파일 삭제 (물리 + DB)
3. 새 파일 업로드 (seq 증가)
4. 기존 파일 메타데이터 업데이트 (seq, description)
5. 전체 파일 목록 반환 (URL 포함)
```

### 썸네일 생성

`ImageResizeUtil.resize(source, target, maxWidth, maxHeight)`

- 라이브러리: Thumbnailator
- 지원 포맷: jpg, jpeg, png, bmp (gif, webp, svg 제외)
- 비율 유지, 업스케일 방지 (원본이 작으면 그대로 복사)
- 업로드 시 자동 생성:
  - 썸네일: 300×300
  - 미리보기: 800×800

### 응답 DTO (BoardFileResponse)

MapStruct 매퍼가 URL 경로를 자동 생성:

```
extension    : 원본 파일명에서 추출
downloadUrl  : /file/download/{menuId}/{idx}
imageUrl     : /static/board/original/{menuId}/{postIdx}/{storedName}
thumbnailUrl : /static/board/thumb/{menuId}/{postIdx}/{storedName} (이미지만)
previewUrl   : /static/board/preview/{menuId}/{postIdx}/{storedName} (이미지만)
```

## 2. 에셋 관리

### 핵심 파일

| 파일 | 역할 |
|---|---|
| `controller/cms/core/asset/AssetController.java` | 에셋 API |
| `service/cms/core/asset/AssetService.java` | 에셋 CRUD |

### API

모든 엔드포인트는 MANAGE 권한 필요.

```
GET    /back-api/asset/list?path=...    → 디렉토리 탐색
POST   /back-api/asset/upload?path=...  → 파일 업로드
DELETE /back-api/asset/delete           → 파일 삭제
POST   /back-api/asset/folder           → 폴더 생성
DELETE /back-api/asset/folder           → 빈 폴더 삭제
```

### 저장 구조

```
{paths.shared-root}/public/images/
├── {카테고리}/
│   ├── logo.png
│   └── banner.jpg
```

공개 URL: `/public/images/{경로}`

### 파일 검증

- **허용 확장자**: jpg, jpeg, png, gif, webp, svg, ico
- **파일명 새니타이징**: 특수문자 제거 (한글/영문/숫자/하이픈/언더스코어만 허용)
- **중복 방지**: 같은 이름 존재 시 `_{타임스탬프}` 접미사 추가
- **경로 순회 방지**: ".." , 절대 경로, 콜론 차단. 해석된 경로가 기본 디렉토리 내인지 검증

### 응답 DTO (AssetItem)

```
name   : 파일/폴더명
type   : "file" 또는 "folder"
size   : 파일 크기 (bytes)
url    : /public/images/... (파일만)
width  : 이미지 너비 (px)
height : 이미지 높이 (px)
```

## 보안

| 기능 | 게시판 파일 | 에셋 |
|---|---|---|
| 조회 | ACCESS 권한 | MANAGE 권한 |
| 업로드 | WRITE 권한 | MANAGE 권한 |
| 삭제 | MODIFY 권한 | MANAGE 권한 |
| 경로 순회 방지 | O | O |

## 환경변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `file.upload.base-path` | `/data/egovframe-cms/uploads/board` | 파일 업로드 물리 경로 |
| `file.public.base-path` | `/static/board` | 파일 공개 URL 프리픽스 |
| `asset.images.base-path` | `${paths.shared-root}/public/images` | 에셋 물리 경로 |
| `paths.shared-root` | `${SHARED_DIR:/data/shared}` | 공유 루트 디렉토리 |
