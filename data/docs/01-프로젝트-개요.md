# Q-CMS 프로젝트 개요

## Q-CMS란

Q-CMS는 멀티사이트를 지원하는 웹 콘텐츠 관리 솔루션(CMS)이다. 하나의 백엔드 + 프론트엔드 인스턴스로 여러 사이트를 운영하며, 각 사이트별로 독립적인 메뉴, 게시판, 콘텐츠, 권한, CSS를 관리한다.

## 기술 스택

### 백엔드
- **Spring Boot 2.7.18** (Java 17)
- **eGov Framework 4.3.0** — 전자정부 프레임워크 호환
- **JPA + QueryDSL 4.4.0** — ORM + 타입 안전 쿼리
- **MapStruct 1.5.5** — DTO ↔ Entity 자동 매핑
- **Spring Security + JWT** — 쿠키 기반 인증
- **Redis** — 세션 관리, 캐싱
- **MySQL 8.0** — 메인 DB (utf8mb4)
- **Gradle** — 빌드 도구

### 프론트엔드
- **Nuxt 3.17** (Vue 3.5, SSR)
- **Pinia** — 상태 관리 (persistedstate)
- **Element Plus** — UI 컴포넌트
- **Tailwind CSS** — 유틸리티 스타일링 (business 사이트 전용)
- **TanStack Vue Query** — 서버 상태 관리
- **CodeMirror 6** — CSS 실시간 편집기
- **Zod** — 스키마 유효성 검증

### 인프라
- **Docker Compose** — MySQL, Redis, Gitea, Jenkins 통합 실행
- **Gitea** — 사내 Git 저장소
- **Jenkins** — CI/CD 파이프라인
- **Nginx** — 리버스 프록시

## 멀티사이트 구조

하나의 Q-CMS 인스턴스가 URL 경로로 사이트를 구분한다.

```
http://domain/www/...        → 사용자 사이트 (메인)
http://domain/business/...   → 관리자 사이트
http://domain/common/login   → 공통 로그인
```

각 사이트별 독립 관리 항목:
- 메뉴 트리 (folder, board, content, script, link)
- 게시판 (LIST, GALLERY, FLOW 타입)
- 콘텐츠 (HTML 에디터)
- 권한 (역할별 메뉴/게시판 접근 제어)
- CSS (사이트별 커스텀 스타일)
- IP 접근 제어 (CIDR 기반 허용/차단)

## 주요 기능 목록

### 사이트 관리
- 사이트 등록/수정/삭제, 개폐 설정
- 사이트별 IP 접근 제어

### 메뉴 관리
- 트리 구조 메뉴 (드래그앤드롭 정렬)
- 메뉴 타입: folder(폴더), board(게시판), content(콘텐츠), script(커스텀 페이지), link(외부 링크)
- 메뉴별 권한 설정

### 게시판
- 동적 게시판: 관리자가 필드를 정의하면 DDL 자동 생성
- 게시판 타입: LIST(목록), GALLERY(갤러리), FLOW(흐름)
- 게시판 옵션: 관리자답변, 대댓글, 비공개, 기간설정, 상단고정, 작성자만보기, 작성자 마스킹, 신규 뱃지, 첨부파일
- 테마 시스템: Loader.vue + Ori.vue + overrides

### 콘텐츠
- HTML 콘텐츠 관리 (에디터)
- 버전 관리
- 메뉴와 연결

### 팝업/배너
- LAYER(모달 팝업) + VISUAL(인라인 배너)
- 이미지별 기간 설정, 자동 슬라이드

### 파일/에셋
- 파일 업로드 (50MB 제한), 이미지 리사이즈
- 에셋 디렉토리 탐색, 클립보드 경로 복사

### 관리자
- 대시보드, 회원 관리, 접근 로그
- CSS 실시간 편집 (CodeMirror, 잠금 메커니즘)
- 권한 관리 (역할별 메뉴/게시판 접근)

## 인프라 서비스 포트

| 서비스 | 컨테이너명 | 포트 | 용도 |
|---|---|---|---|
| MySQL 8.0 | jh-mysql | 3306 | 메인 DB |
| Redis 7 | jh-redis | 6379 | 세션/캐시 |
| Gitea | jh-gitea | 4000 (→내부 3000) | Git 저장소 |
| Jenkins | jh-jenkins | 9090 (→내부 8080) | CI/CD |
| Backend | jh-half-backend | 8080 | Spring Boot API |
| Frontend | jh-half-frontend | 3000 | Nuxt SSR |

## API 경로 규칙

모든 백엔드 API는 `/back-api/` 프리픽스를 사용한다.

```
/back-api/auth/login          인증
/back-api/site/...            사이트 관리
/back-api/menu/...            메뉴 관리
/back-api/boardMaster/...     게시판 마스터
/back-api/content/...         콘텐츠 관리
/back-api/render/...          렌더링 데이터 (공개)
/back-api/file/...            파일 업로드/다운로드
```
