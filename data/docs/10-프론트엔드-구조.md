## nuxt.config.ts 핵심 설정

```typescript
// SSR 활성화
ssr: true

// 모듈
modules: [pinia, pinia-persist, tailwindcss, device, element-plus, color-mode, swiper]

// 런타임 설정
runtimeConfig: {
  logLevel: 'info'                                // 서버 로그 레벨
  enableConsoleLog: false                          // 콘솔 로그 활성화
  apiBase: 'http://localhost:8080/back-api'       // SSR 전용 (Docker 내부)
  public: {
    cssVersion: 'YYYYMMDDHHmm'                    // CSS 캐시 버스팅 (빌드 시 생성)
    baseUrl: 'http://localhost'                    // 사이트 기본 URL
    apiBase: 'http://localhost/back-api'           // CSR용 (Nginx 경유)
    baseLoginUrl: '/www/support/member_login'      // 로그인 URL
    cmsAllowedIps: ['127.0.0.1', '172.16.0.0/12'] // 허용 IP (배열, CIDR)
  }
}
```

**SSR/CSR API 호출 분리:**
- SSR: `NUXT_API_BASE` → Docker 내부 직접 호출 (jh-half-backend:8080)
- CSR: `NUXT_PUBLIC_API_BASE` → Nginx 경유 (/back-api)

## Pinia 스토어

### siteStore

사이트 정보 관리.

```typescript
state: {
  site: string              // 현재 사이트명 (예: "www")
  siteList: Site[]           // 전체 사이트 목록
}
computed: {
  activeSites              // isDeleted === false인 사이트
}
actions: {
  setSite(name)
  fetchSiteList()          // GET /api/json/site
}
```

### menuStore

메뉴 트리 + 현재 메뉴.

```typescript
state: {
  menuTree: MenuItem[]       // 메뉴 트리 (재귀)
  currentMenuId: number      // 현재 활성 메뉴
  lastLoadedSite: string     // 마지막 로드 사이트
}
computed: {
  breadcrumb               // 부모 체인 (빵가루)
  breadcrumbTitle           // 마지막 메뉴 제목
}
actions: {
  fetchMenuTree(site)      // GET /api/json/menu?site={site}
  setCurrentMenuByPath(path)
  findRoutePath(id)
}
```

### renderStore

페이지 렌더링 데이터.

```typescript
state: {
  data: RenderData          // { type, value, option, permission }
  option: BoardOption       // 게시판 설정
  permission: BoardPermission // 권한 정보
  fieldDefinitions: BoardFieldDef[] // 필드 정의
}
actions: {
  fetchRenderData()        // GET /render (X-Menu-Id, X-Site-Hostname 헤더 포함)
  clear()
}
```

### userStore

사용자 인증 정보.

```typescript
state: {
  user: UserInfo            // { userId, userName, level, idx }
  initialized: boolean
}
computed: {
  isAdmin                  // level === 1
  isGuest                  // !user || idx === -1
}
actions: {
  fetchUser()              // GET /auth/me
  initUser()               // 지연 초기화
}
```

### uiStore

UI 상태 (모바일, 사이드바).

```typescript
state: {
  isMobile: boolean         // window.innerWidth <= 768
  isSidebarCollapsed: boolean
  showMobileSidebar: boolean
}
```

## 레이아웃

미들웨어 01b에서 URL 깊이 + 사이트명에 따라 자동 선택.

| 레이아웃 | 사용처 |
|---|---|
| www-main | www 사이트 메인 페이지 |
| www-sub | www 사이트 서브 페이지 |
| business-sub | 관리자 페이지 (항상) |
| default-main | 폴백 메인 |
| default-sub | 폴백 서브 |

선택 로직: `{사이트}-{main|sub}` → `default-{main|sub}` → `default`

## 서버 사이드 (server/)

### API 라우트

```
GET /api/health/check        → 헬스 체크
GET /api/css-version         → CSS 버전 (캐시 버스팅)
GET /api/json/site           → 사이트 목록 (JSON)
GET /api/json/menu?site=www  → 메뉴 트리 (JSON)
```

### 서버 미들웨어

- `security-headers.ts` — CSP, X-Frame-Options, CORS 헤더 설정
- `css-version.ts` — CSS 버전 값 주입

## 환경변수

| 변수 | 설명 |
|---|---|
| `NUXT_API_BASE` | SSR 백엔드 URL (Docker 내부) |
| `NUXT_PUBLIC_API_BASE` | CSR 백엔드 URL (Nginx 경유) |
| `NUXT_PUBLIC_BASE_URL` | 사이트 기본 URL |
| `CMS_JSON_ROOT` | JSON 캐시 디렉토리 |
| `CMS_BASE_URL` | CMS 기본 URL |
| `CMS_ALLOWED_IPS` | 허용 IP 목록 (CIDR) |
| `DEV_PROXY_ORIGIN` | 개발 시 프록시 원본 URL |

## 빌드 명령

```bash
npm install    # 의존성 설치
npm run dev    # 개발 서버 (포트 3000, Hot Reload)
npm run build  # 프로덕션 빌드 (.output/)
npm run start  # 빌드된 앱 실행
```
