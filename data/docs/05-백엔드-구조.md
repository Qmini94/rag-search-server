## 레이어 구조

```
Controller → Service(Interface) → ServiceImpl → Repository/DAO
                                       ↓
                                  Entity ↔ DTO (MapStruct)
```

### Controller
- `@RestController` + `@RequestMapping("/back-api/...")`
- 요청 DTO 검증, 서비스 호출, 응답 반환
- 파일: `controller/cms/core/{도메인}/{도메인}Controller.java`

### Service
- Interface + Impl 분리
- 비즈니스 로직 집중
- 트랜잭션 관리 (`@Transactional`)
- 파일: `service/cms/core/{도메인}/impl/{도메인}ServiceImpl.java`

### Repository
- JPA Repository: 기본 CRUD (`extends JpaRepository`)
- Custom Repository: QueryDSL 복잡 쿼리 (`...RepositoryCustom` + `...RepositoryCustomImpl`)
- DAO: 동적 SQL, DDL (`DynamicBoardDao`, `BoardSchemaDaoImpl`)
- 파일: `repository/cms/core/{도메인}/`

### Entity
- JPA 어노테이션 (`@Entity`, `@Table`)
- Lombok (`@Getter`, `@Builder`, `@NoArgsConstructor`)
- 파일: `entity/cms/core/{도메인}/`

### DTO
- Request/Response 분리
- Paging, Search 공통 DTO 존재
- 파일: `dto/cms/core/` 또는 `dto/auth/`

### Mapper (MapStruct)
- Entity ↔ DTO 자동 변환
- `@Mapper(componentModel = "spring")`
- 파일: `mapper/{도메인}Mapper.java`

## QueryDSL 설정

`build.gradle`에서 Q클래스 자동 생성:

```groovy
def querydslDir = "$buildDir/generated/querydsl"

task generateQueryDSL(type: JavaCompile) {
    source = sourceSets.main.java
    classpath = configurations.querydsl
    options.annotationProcessorPath = configurations.querydsl
    options.compilerArgs = ["-proc:only", "-processor", "com.querydsl.apt.jpa.JPAAnnotationProcessor"]
    destinationDir = file(querydslDir)
}

compileJava { dependsOn generateQueryDSL }
```

빌드 시 `compileJava` 전에 `generateQueryDSL`이 실행되어 Q클래스가 생성된다.

## API 패턴

### 목록 조회 (페이징)

```java
@GetMapping("/boardMaster")
public ResponseEntity<?> list(
    @RequestParam(defaultValue = "0") int page,
    @RequestParam(defaultValue = "10") int size,
    @RequestParam(required = false) String keyword) {
    return ResponseEntity.ok(boardMasterService.search(page, size, keyword));
}
```

### 단건 조회

```java
@GetMapping("/boardMaster/{idx}")
public ResponseEntity<?> detail(@PathVariable Long idx) {
    return ResponseEntity.ok(boardMasterService.findById(idx));
}
```
