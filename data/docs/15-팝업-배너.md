# 팝업 및 배너

## 개요

Q-CMS는 두 가지 팝업 타입을 지원한다:
- **LAYER** — 고정 좌표 다이얼로그 팝업 (팝업 단위 스케줄링)
- **VISUAL** — 이미지 캐러셀 배너 (이미지별 스케줄링)

## 핵심 파일

### 백엔드

| 파일 | 역할 |
|---|---|
| `controller/cms/core/popup/PopupController.java` | 팝업 API |
| `service/cms/core/popup/PopupService.java` | 팝업 CRUD + 활성 조회 |
| `entity/cms/core/popup/Popup.java` | 팝업 엔티티 |
| `entity/cms/core/popup/PopupImage.java` | 팝업 이미지 엔티티 |
| `enums/PopupType.java` | LAYER, VISUAL 열거형 |

### 프론트엔드

| 파일 | 역할 |
|---|---|
| `composables/api/render/usePopup.ts` | 팝업 조회 |
| `composables/api/render/useVisualBanner.ts` | 배너 캐러셀 |
| `components/business/popup/` | 관리자 팝업 컴포넌트 |

## 팝업 타입

### LAYER (레이어 팝업)

화면 고정 위치에 표시되는 다이얼로그형 팝업.

```
속성:
  title        : 팝업 제목
  hostname     : 사이트 호스트명
  leftPx, topPx: 좌측/상단 위치 (px)
  width, height: 크기 (px)
  startDate    : 게시 시작일
  endDate      : 게시 종료일
  useTodayHide : "오늘 하루 보지 않기" 기능
  sortOrder    : 표시 순서
  isUse        : 사용 여부
```

**활성 조건:** `isUse=true` AND 현재 시간이 `[startDate, endDate]` 범위 내

### VISUAL (비주얼 배너)

이미지 캐러셀/슬라이더형 배너.

```
속성:
  title         : 배너 제목
  hostname      : 사이트 호스트명
  autoSlide     : 자동 슬라이드 여부
  slideInterval : 자동 슬라이드 간격 (초)
  slideEffect   : 애니메이션 효과 (fade/slide)
  isUse         : 사용 여부
  images[]      : 이미지 목록 (각각 개별 스케줄링)
```

**위치/크기 필드:** VISUAL에서는 무시됨 (저장 시 무시)

**활성 조건:** `isUse=true` AND `isUse=true`인 이미지 중 현재 시간이 `[image.startDate, image.endDate]` 범위 내인 것이 1개 이상

## 엔티티

### Popup (cms_popup)

| 필드 | 타입 | 설명 |
|---|---|---|
| idx | Long (PK) | 팝업 ID |
| type | PopupType | LAYER or VISUAL |
| hostname | String(50) | 사이트 호스트명 |
| title | String(100) | 제목 |
| leftPx, topPx | Integer | LAYER 위치 |
| width, height | Integer | LAYER 크기 |
| sortOrder | Integer | 표시 순서 |
| startDate | LocalDateTime | LAYER 시작일 |
| endDate | LocalDateTime | LAYER 종료일 |
| useTodayHide | Boolean | 오늘 하루 보지 않기 |
| isUse | Boolean | 사용 여부 |
| autoSlide | Boolean | VISUAL 자동 슬라이드 |
| slideInterval | Integer | VISUAL 슬라이드 간격 (초) |
| slideEffect | String | VISUAL 효과 |
| images | List<PopupImage> | Cascade 이미지 목록 |

### PopupImage (cms_popup_image)

| 필드 | 타입 | 설명 |
|---|---|---|
| idx | Long (PK) | 이미지 ID |
| popup | Popup (FK) | 팝업 참조 |
| imageUrl | String | 공개 URL |
| title | String | 이미지 제목 |
| linkUrl | String | 클릭 링크 URL |
| linkTarget | String | 링크 타겟 (_blank 등) |
| sortOrder | Integer | 정렬 순서 |
| startDate | LocalDateTime | VISUAL 이미지 시작일 |
| endDate | LocalDateTime | VISUAL 이미지 종료일 |
| isUse | Boolean | 사용 여부 |

## API

### 관리자 API

```
GET    /back-api/popup                           → 목록 (페이징, 검색, 타입 필터)
GET    /back-api/popup/{idx}                     → 단건 조회
POST   /back-api/popup                           → 생성
PUT    /back-api/popup/{idx}                     → 수정
DELETE /back-api/popup/{idx}                     → 삭제 (이미지+디렉토리 함께)
```

### 이미지 관리 API

```
POST   /back-api/popup/{idx}/images             → 이미지 업로드
DELETE /back-api/popup/{idx}/images/{imageIdx}   → 이미지 삭제
PUT    /back-api/popup/{idx}/images/order        → 이미지 순서 변경
PUT    /back-api/popup/images/{imageIdx}/link    → 이미지 링크 수정
PUT    /back-api/popup/images/{imageIdx}         → 이미지 메타 수정
```

### 공개 API

```
GET    /back-api/popup/active?hostname=www       → 활성 레이어 팝업 목록
GET    /back-api/popup/{idx}/active-images       → 활성 배너 이미지 목록
```

## 파일 저장

```
{contentBasePath}/popup/{popupIdx}/
├── {UUID}.jpg
├── {UUID}.png
└── ...
```

- 허용 확장자: jpg, jpeg, png, gif, webp, svg
- 최대 파일 크기: 25MB
- 팝업별 디렉토리 자동 생성
- 공개 URL: `{publicUrlPrefix}/popup/{popupIdx}/{storedName}`

## 삭제 시 동작

팝업 삭제 시 cascade로 이미지 DB 레코드 + 물리 파일 + 디렉토리가 함께 삭제된다.

## 프론트엔드 사용

### 레이어 팝업 (usePopup)

```typescript
// 페이지 로드 시 활성 팝업 조회
const { activePopups } = usePopup(hostname)
// → 쿠키로 "오늘 하루 보지 않기" 처리
```

### 비주얼 배너 (useVisualBanner)

```typescript
// Swiper 캐러셀로 배너 표시
const { bannerImages, autoSlide, slideInterval } = useVisualBanner(popupIdx)
```

## 권한

| 동작 | 필요 권한 |
|---|---|
| 목록/상세 | ACCESS |
| 생성 | WRITE |
| 수정 | MODIFY |
| 삭제 | REMOVE |
| 활성 조회 (공개) | 없음 |
