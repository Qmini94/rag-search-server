## 2. 각 컴포넌트 상세

### SafeHtml.vue

DOMPurify 기반의 HTML 새니타이징 렌더 컴포넌트. `utils/validator`의 `sanitizeHtml` 유틸을 사용하며, 콘텐츠가 없을 때는 준비 중 이미지를 표시한다. `<script>`, `<iframe>`, 이벤트 핸들러 속성 등은 CSS로도 추가 차단한다.

#### Props

| 이름 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `content` | `string` | `""` | 새니타이징할 원본 HTML 문자열 |
| `allowedTags` | `string[]` | `undefined` | 허용할 HTML 태그 목록 (미지정 시 기본값 사용) |
| `allowedAttributes` | `string[]` | `undefined` | 허용할 HTML 속성 목록 |
| `stripTags` | `boolean` | `false` | `true`이면 모든 태그를 제거하고 텍스트만 반환 |
| `wrapperClass` | `string` | `""` | 래퍼 `<div>`에 적용할 CSS 클래스 |
| `showPlaceholder` | `boolean` | `true` | 콘텐츠가 없을 때 플레이스홀더 표시 여부 |
| `placeholderText` | `string` | `"내용이 없습니다."` | 플레이스홀더 텍스트 |
| `placeholderClass` | `string` | `"text-gray-500 italic"` | 플레이스홀더 CSS 클래스 |

#### Slots / Emits

없음 (props 전용 컴포넌트)

#### 사용 예시

```vue
<SafeHtml :content="article.content" wrapper-class="prose max-w-none" />

<!-- 태그 제거 후 텍스트만 -->
<SafeHtml :content="article.summary" :strip-tags="true" />
```

#### 보안 동작

- `content`가 비어 있으면 준비 중 이미지(`/public/images/halftour/common/c_soon_halftour.png`) 출력
- `scoped` 스타일로 `script`, `object`, `embed`, `iframe` 태그 `display: none` 강제 적용
- `onload`, `onerror`, `onclick` 등 인라인 이벤트 속성 `pointer-events: none` 적용

### WidgetList.vue

메인페이지에서 특정 게시판(menuId)의 최신 게시글을 불러와 템플릿 문자열(`itemTemplate`)로 렌더링하는 위젯 컴포넌트. `safeFetch`로 `/board` API를 호출하며 마운트 시점에 데이터를 로드한다.

#### Props

| 이름 | 타입 | 필수 | 기본값 | 설명 |
|---|---|---|---|---|
| `menuId` | `string \| number` | Y | - | 조회할 게시판 메뉴 ID |
| `size` | `number` | Y | - | 가져올 게시글 수 |
| `itemTemplate` | `string` | Y | - | 각 아이템 렌더링 HTML 템플릿 문자열 |
| `wrapperTag` | `string` | N | `"ul"` | 래퍼 요소 태그명 |
| `wrapperClass` | `string` | N | - | 래퍼 요소 CSS 클래스 |
| `wrapperId` | `string` | N | - | 래퍼 요소 id 속성 |
| `params` | `Record<string, any>` | N | - | API 추가 쿼리 파라미터 |
| `forceFields` | `Record<string, any>` | N | - | 각 아이템에 강제로 덮어쓸 필드 |
| `timeout` | `number` | N | `2000` | API 요청 타임아웃(ms) |
| `linkToList` | `boolean` | N | `false` | `true`이면 아이템 URL을 상세가 아닌 목록 페이지로 생성 |

#### 템플릿 변수

`itemTemplate` 문자열 안에서 `{%필드명}` 형식으로 데이터를 바인딩한다. `{%raw:필드명}`은 HTML 이스케이프 없이 원본값 출력.

| 변수 | 설명 |
|---|---|
| `{%title}` | 제목 |
| `{%url}` | 상세 링크 URL |
| `{%img}` | 이미지 URL |
| `{%alt}` | 이미지 alt 텍스트 |
| `{%desc}` | 본문 요약 |
| `{%date}` | 등록일 (YYYY.MM.DD) |
| `{%day}` | 일(DD) |
| `{%month}` | 연월(YYYY.MM) |
| `{%raw:newBadge}` | 7일 이내 새글 배지 HTML (raw 필요) |
| `{%idx}` | 0-based 인덱스 |
| `{%no}` | 1-based 번호 |

#### Slots / Emits

없음 (템플릿 문자열 기반 렌더링)

#### 사용 예시

```vue
<WidgetList
  :menu-id="42"
  :size="5"
  wrapper-tag="ul"
  wrapper-class="notice_list"
  item-template="<li><a href='{%url}'>{%title}</a><span>{%date}</span></li>"
/>
```

### VisualBanner.vue

`useVisualBanner` composable과 연동하는 슬라이드 배너 컴포넌트. 렌더링 로직은 composable에 위임하고, 슬롯을 통해 슬라이드 제어 상태를 모두 외부로 노출하는 headless 패턴이다. `await` 방식으로 composable을 호출하므로 **Suspense** 래퍼가 필요하다.

#### Props

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `popupId` | `number` | Y | 비주얼 배너 팝업 ID |

#### Slots

| 슬롯 | 설명 |
|---|---|
| `default` | 배너 렌더링 슬롯. `items.length > 0`일 때만 렌더링됨 |

슬롯 스코프(slot props):

| 이름 | 타입 | 설명 |
|---|---|---|
| `items` | `array` | 배너 이미지 목록 |
| `currentIndex` | `number` | 현재 활성 슬라이드 인덱스 |
| `prevIndex` | `number` | 이전 슬라이드 인덱스 |
| `current` | `object` | 현재 슬라이드 데이터 |
| `total` | `number` | 전체 슬라이드 수 |
| `slideEffect` | `string` | 슬라이드 효과 타입 |
| `effectClass` | `string` | 적용할 CSS 클래스 |
| `next` | `() => void` | 다음 슬라이드로 이동 |
| `prev` | `() => void` | 이전 슬라이드로 이동 |
| `goTo` | `(idx: number) => void` | 특정 인덱스로 이동 |
| `pause` | `() => void` | 자동 재생 일시정지 |
| `resume` | `() => void` | 자동 재생 재개 |
| `togglePause` | `() => void` | 일시정지/재개 토글 |
| `isPaused` | `boolean` | 현재 일시정지 상태 |

#### 사용 예시

```vue
<Suspense>
  <VisualBanner :popup-id="1">
    <template #default="{ items, currentIndex, next, prev, goTo, isPaused, togglePause }">
      <div class="visual_slide">
        <ul>
          <li
            v-for="(item, idx) in items"
            :key="idx"
            :class="{ active: idx === currentIndex }"
          >
            <img :src="item.imageUrl" :alt="item.altText" />
          </li>
        </ul>
        <button @click="prev">이전</button>
        <button @click="next">다음</button>
        <button @click="togglePause">{{ isPaused ? '재생' : '정지' }}</button>
      </div>
    </template>
  </VisualBanner>
</Suspense>
```

### PopupLayer.vue

`usePopup` composable과 연동하여 레이어 팝업을 전역으로 표시하는 컴포넌트. 팝업 위치(left/top), 크기(width/height), 슬라이드 효과, 오늘 하루 보지 않기, 자동 슬라이드 기능을 모두 내장한다. 전역 레이아웃(`app.vue` 또는 최상위 레이아웃)에 한 번 배치한다.

#### Props

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `hostname` | `string` | Y | 팝업을 조회할 사이트 hostname |

#### 내부 동작

- `usePopup(hostname)`으로 `visiblePopups` 목록 취득
- 팝업당 슬라이드 인덱스(`slideIndices`)와 타이머(`slideTimers`)를 `ref`로 관리
- `watch(visiblePopups)`: 팝업 목록 변경 시 기존 타이머 정리 후 새 타이머 시작
- `hideToday(idx)`: 오늘 하루 보지 않기 (cookie/localStorage 기반, composable 처리)
- `closePopup(idx)`: 팝업 닫기
- 슬라이드 효과: `fade` / `slide` / `none` (팝업 설정의 `slideEffect` 필드)

#### Slots / Emits

없음 (완결형 컴포넌트)

#### 사용 예시

```vue
<!-- app.vue 또는 layouts/default.vue -->
<PopupLayer :hostname="currentHostname" />
```

### ButtonGroup.vue

게시판 상세 페이지의 액션 버튼 모음. `boardCoreKey` inject로 게시판 컨텍스트를 주입받아 수정/삭제 가능 여부를 판단한다. 권한(`permission`) prop이 없으면 아무것도 렌더링하지 않는다.

#### Props

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `permission` | `BoardPermission \| null` | Y | 게시판 권한 객체 |

#### 버튼 노출 조건

| 버튼 | 노출 조건 |
|---|---|
| 목록 | 항상 표시 (permission이 있을 때) |
| 등록 | `permission.write === true` |
| 수정 | `board.canModify(permission) === true` |
| 삭제 | `board.canRemove(permission) === true` |

#### 내부 동작

- `boardCoreKey` 또는 `"boardContext"` inject로 board 컨텍스트 획득
- 목록: `router.push({ path, query: {} })`
- 등록: `router.push({ query: { mode: 'write' } })`
- 수정: `router.push({ query: { mode: 'modify', idx } })`
- 삭제: `board.deleteArticle()` 호출 후 에러 시 알럿

#### Slots / Emits

없음

### RoundedCard.vue

관리자 화면 등에서 사용하는 범용 카드 UI 래퍼. 제목 슬롯과 기본 콘텐츠 슬롯으로 구성된다.

| 이름 | 타입 | 기본값 | 설명 |

| `scrollX` | `boolean` | `false` | 콘텐츠 영역 가로 스크롤 허용 여부 |

#### Slots

| 슬롯 | 설명 |
|---|---|

```vue
<RoundedCard :padding="false" :scroll-x="true">
  <table>...</table>
</RoundedCard>
```

#### 사용 위치


### render/board/Search.vue

게시판 테마 컴포넌트 내부에서 사용하는 검색 바. `boardCoreKey`를 `inject`하여 검색 조건을 URL 쿼리로 반영한다.

- 검색 실행: `board.updateQuery({ page: 0, keyword, type, isUse, startDate, endDate, size })`
- 페이지 사이즈 옵션: 5 / 10 / 15 / 30

#### Props / Slots / Emits

없음 (inject 기반)

#### 사용 위치

```vue
<!-- 게시판 테마 컴포넌트 내부 -->
<CommonRenderBoardSearch />
```

## 3. 사용 패턴

### 슬롯 기반 컴포넌트 사용법

`VisualBanner`와 `RoundedCard`는 슬롯으로 렌더링 로직을 외부에 위임한다.

```vue
<!-- VisualBanner: 슬롯 스코프로 상태 수신 -->
<VisualBanner :popup-id="1">
  <template #default="{ items, currentIndex, next, prev }">
    <!-- 실제 HTML 구현 -->
  </template>
</VisualBanner>

<!-- RoundedCard: named slot으로 제목 커스터마이즈 -->
<RoundedCard>
  <template #title>커스텀 제목</template>
  <p>본문 내용</p>
</RoundedCard>
```

### Props 전달 패턴

```vue
<!-- Boolean props: 값 없이 쓰면 true -->
<RoundedCard :scroll-x="true" :padding="false" />

<!-- 동적 타입 바인딩 -->
<AppIcon :type="menuItem.menuType" :size="'sm'" />

<!-- SafeHtml: 허용 태그 제한 -->
<SafeHtml
  :content="rawHtml"
  :allowed-tags="['p', 'strong', 'em', 'ul', 'li']"
  wrapper-class="ck-content"
/>
```

### 이벤트 emit 패턴

`common/` 컴포넌트들은 대부분 emit을 사용하지 않고 내부적으로 `router`, `inject`를 통해 상태를 변경한다.

- `ButtonGroup` / `ButtonListPage`: `router.push()`로 직접 내비게이션
- `render/board/Pagination` / `Search`: `board.updateQuery()`로 URL 쿼리 갱신 (부모 컴포넌트가 watch로 반응)

## 4. www 공통 컴포넌트

### www/common/QuickArea.vue

www 사이트 전용 퀵메뉴 영역. `<aside id="aside">`로 렌더링되며, 열림/닫힘 상태(`isOpen`)를 내부 `ref`로 관리한다.

#### Props / Emits

없음 (완결형 컴포넌트)

#### 내부 동작

- 초기 상태: `isOpen = true` (열린 상태로 시작)
- OPEN 버튼 클릭 → `isOpen = true`
- CLOSE 버튼 클릭 → `isOpen = false`
- TOP 버튼 클릭 → `window.scrollTo({ top: 0, behavior: 'smooth' })`

#### 포함 링크 (하드코딩)

| 텍스트 | URL |
|---|---|
| 여행사전신청 | `http://jhhalf.mx.co.kr/www/half/apply` |
| 증빙자료업로드 | `http://jhhalf.mx.co.kr/www/half/myApplication` |

#### 사용 예시

```vue
<!-- layouts/www/default.vue -->
<WwwCommonQuickArea />
```
