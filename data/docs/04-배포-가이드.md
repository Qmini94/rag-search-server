# 배포 가이드

## 서버 요구사항

- OS: Rocky Linux 9 (또는 CentOS/RHEL 계열)
- Docker + Docker Compose
- 최소 8GB RAM, 50GB 디스크

## 디렉토리 구조

서버에 아래 디렉토리를 생성한다.

```bash
mkdir -p /data/jh_half/{docker/{mysql,redis,gitea,jenkins},shared/{contents,public/{images,style},json},install,deploy/{backend,frontend}}
```

```
/data/jh_half/
├── docker/
│   ├── mysql/          MySQL 데이터
│   ├── redis/          Redis 데이터
│   ├── gitea/          Gitea 데이터
│   └── jenkins/        Jenkins 홈
├── shared/             앱 공유 디렉토리
│   ├── contents/       콘텐츠 파일
│   ├── public/
│   │   ├── images/     에셋 이미지
│   │   └── style/      사이트별 CSS
│   └── json/           메뉴/사이트 JSON 캐시
├── install/            설치 파일 (초기 데이터)
└── deploy/             Docker 이미지 저장
    ├── backend/
    └── frontend/
```

## Phase 1: Docker 설치

```bash
# Docker 설치
sudo dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo systemctl enable --now docker

# 현재 유저를 docker 그룹에 추가
sudo usermod -aG docker $USER
```

### 폐쇄망(오프라인) Docker 설치

인터넷이 안 되는 운영 서버의 경우:

```bash
# 인터넷 되는 PC에서 RPM 다운로드
dnf download --resolve --destdir=./docker-rpms docker-ce docker-ce-cli containerd.io docker-compose-plugin

# USB/SCP로 운영 서버에 전송 후 설치
sudo rpm -ivh ./docker-rpms/*.rpm
sudo systemctl enable --now docker
```

## Phase 2: 인프라 실행 (Docker Compose)

```yaml
# docker-compose.yml
version: "3.8"

services:
  mysql:
    image: mysql:8.0
    container_name: jh-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: "Yubi!!@@##64"
      MYSQL_DATABASE: jh_half_q_cms
      MYSQL_CHARSET: utf8mb4
      MYSQL_COLLATION: utf8mb4_unicode_ci
      TZ: Asia/Seoul
    ports: ["3306:3306"]
    volumes:
      - /data/jh_half/docker/mysql:/var/lib/mysql
    command:
      - --character-set-server=utf8mb4
      - --collation-server=utf8mb4_unicode_ci
      - --lower_case_table_names=1

  redis:
    image: redis:7-alpine
    container_name: jh-redis
    restart: unless-stopped
    command: redis-server --requirepass "Yubi!!@@##64"
    ports: ["6379:6379"]
    volumes:
      - /data/jh_half/docker/redis:/data

  gitea:
    image: gitea/gitea:latest
    container_name: jh-gitea
    restart: unless-stopped
    environment:
      - GITEA__database__DB_TYPE=mysql
      - GITEA__database__HOST=mysql:3306
      - GITEA__database__NAME=gitea
      - GITEA__database__USER=root
      - GITEA__database__PASSWD=Yubi!!@@##64
      - GITEA__server__ROOT_URL=http://49.254.140.64:4000/
      - GITEA__server__SSH_DOMAIN=49.254.140.64
      - GITEA__server__SSH_PORT=2222
    ports: ["4000:3000", "2222:22"]
    volumes:
      - /data/jh_half/docker/gitea:/data
    depends_on: [mysql]

  jenkins:
    image: jenkins/jenkins:lts-jdk17
    container_name: jh-jenkins
    restart: unless-stopped
    user: root
    environment:
      - TZ=Asia/Seoul
    ports: ["9090:8080", "50000:50000"]
    volumes:
      - /data/jh_half/docker/jenkins:/var/jenkins_home
      - /var/run/docker.sock:/var/run/docker.sock
      - /usr/bin/docker:/usr/bin/docker
      - /data/jh_half/deploy:/data/jh_half/deploy

networks:
  jh-net:
    driver: bridge
```

```bash
docker compose up -d
```

## Phase 3: Nginx 리버스 프록시

```nginx
server {
    listen 80;
    server_name jhhalf.mx.co.kr;

    # 프론트엔드 (Nuxt SSR)
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 백엔드 API
    location /back-api/ {
        proxy_pass http://127.0.0.1:8080/back-api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 60M;
    }

    # 공유 정적 파일
    location /public/ {
        alias /data/jh_half/shared/public/;
        expires 7d;
        add_header Cache-Control "public, immutable";
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## Phase 4: 앱 배포

### 방법 1: Jenkins 자동 빌드

1. Gitea에 코드 push
2. Jenkins에서 Build Now
3. Docker 이미지 자동 빌드 + 배포
4. `/data/jh_half/deploy/`에 tar.gz 저장

### 방법 2: 이미지 수동 전송 (운영 서버)

```bash
# 중계 서버에서 이미지 전송
scp /data/jh_half/deploy/backend/jh-half-backend.tar.gz user@운영서버:/data/jh_half/deploy/backend/
scp /data/jh_half/deploy/frontend/jh-half-frontend.tar.gz user@운영서버:/data/jh_half/deploy/frontend/

# 운영 서버에서 로드
gunzip -c /data/jh_half/deploy/backend/jh-half-backend.tar.gz | docker load
gunzip -c /data/jh_half/deploy/frontend/jh-half-frontend.tar.gz | docker load

# 컨테이너 실행 (환경변수는 프로젝트에 맞게 설정)
docker stop jh-half-backend || true && docker rm jh-half-backend || true
docker run -d --name jh-half-backend \
  --network docker_jh-net \
  --restart unless-stopped \
  -p 8080:8080 \
  -v /data/jh_half/shared:/data/jh_half/shared \
  -e SPRING_PROFILES_ACTIVE=prod \
  -e DB_HOST=jh-mysql \
  -e DB_NAME=jh_half_q_cms \
  ... (환경변수)
  jh-half-backend:latest

docker stop jh-half-frontend || true && docker rm jh-half-frontend || true
docker run -d --name jh-half-frontend \
  --network docker_jh-net \
  --restart unless-stopped \
  -p 3000:3000 \
  -v /data/jh_half/shared:/data/jh_half/shared \
  -e NUXT_API_BASE=http://jh-half-backend:8080/back-api \
  -e NUXT_PUBLIC_BASE_URL=http://도메인 \
  -e NUXT_PUBLIC_API_BASE=http://도메인/back-api \
  ... (환경변수)
  jh-half-frontend:latest
```

## 포트 매핑 정리

| 외부 포트 | 서비스 | 내부 포트 | 외부 접근 |
|---|---|---|---|
| 80 | Nginx | - | 사용자 접속 |
| 3000 | Nuxt (프론트엔드) | 3000 | Nginx 프록시 |
| 8080 | Spring Boot (백엔드) | 8080 | Nginx 프록시 |
| 3306 | MySQL | 3306 | 내부만 |
| 6379 | Redis | 6379 | 내부만 |
| 4000 | Gitea | 3000 | 개발자 접근 |
| 9090 | Jenkins | 8080 | 개발자 접근 |

## 네트워크 구조

```
[사용자 브라우저]
       │ :80
       ▼
    [Nginx]
    ├── /           → localhost:3000 (Nuxt)
    ├── /back-api/  → localhost:8080 (Spring Boot)
    └── /public/    → /data/jh_half/shared/public/ (정적파일)

[Docker 네트워크: jh-net]
    ├── jh-half-frontend (:3000) → jh-half-backend (:8080)  SSR 직접 호출
    ├── jh-half-backend  (:8080) → jh-mysql (:3306)
    ├── jh-half-backend  (:8080) → jh-redis (:6379)
    └── jh-jenkins       (:9090→8080) → jh-gitea (:4000→3000)
```
